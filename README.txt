# MistakeVault Starter Project

A beginner-friendly project made with HTML, CSS, JavaScript and browser LocalStorage.

## Files
- `index.html` — website structure and page sections
- `style.css` — colours, layout and responsive design
- `script.js` — adding, editing, deleting, searching, filtering, revision, self-test and analytics

## Run it
1. Extract this ZIP file.
2. Open the `MistakeVault` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.
4. Add a test mistake and refresh the browser. Your record should still be there.

## Important
This is a frontend learning prototype. It stores records in the current browser using LocalStorage. It does not provide secure login, cloud sync, or cross-device accounts. Do not store passwords or sensitive personal data in this demo.

## Suggested first test
- Topic: Binary Conversion
- Category: Calculation
- Question: Convert decimal 13 into binary.
- Incorrect answer: 1010
- Why wrong: I stopped the division process too early and missed the final remainder.
- Correct understanding: Repeatedly divide by 2 and read the remainders from bottom to top. The correct answer is 1101.
- Revision date: choose today's date
